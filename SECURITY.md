# Security Policy

## Scope

The Password Generator app (`io.github.danst0.passwordgenerator`), its source
code in this repository and the Flatpak build published on Flathub.

## Supported versions

Only the latest stable release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/danst0/passwordgenerator/security/advisories/new)
and do not open a public issue. Reports in English or German are welcome.

Reports are acknowledged within 72 hours. We aim for coordinated disclosure
once a fix is available.
